## 2024-12-19

### 修复：元数据注释格式优化

**问题描述：**
- 在看板视图中填写的属性-值在保存到 markdown 文档时会换行
- 元数据注释 `<!-- kanban-item-metadata: {...} -->` 没有放在 `- [ ]` 的包裹下，导致渲染出现问题
- 需要将属性-值追加到内容的最后一行，每个属性-值单独一行记录

**修复内容：**
- 修改 `src/parsers/helpers/parser.ts` 中的 `addItemMetadata` 函数
- 将元数据注释追加到内容的最后一行（如果内容有多行，追加到最后一行）
- 每个属性-值单独一行记录，保持缩进与内容一致
- 确保元数据注释始终保持在 `- [ ]` 列表项的包裹下（通过缩进实现）

**涉及文件：**
- `src/parsers/helpers/parser.ts` - 修改 `addItemMetadata` 函数，将元数据注释追加到最后一行，每个属性-值单独一行
- `src/parsers/formats/list.ts` - 更新 `listItemToItemData` 函数，支持读取多行的元数据注释（每个属性一行）

**修改前：**
```markdown
- [ ] 得大点

<!-- kanban-item-metadata: {"负责人":"jr"} -->
```

**修改后（单行内容）：**
```markdown
- [ ] 得大点
    <!-- kanban-item-metadata: {"负责人":"jr"} -->
```

**修改后（多行内容）：**
```markdown
- [ ] 第一行
    第二行
    <!-- kanban-item-metadata: {"负责人":"jr"} -->
```

**修改后（多个属性）：**
```markdown
- [ ] 得大点
    <!-- kanban-item-metadata: {"负责人":"jr"} -->
    <!-- kanban-item-metadata: {"优先级":"高"} -->
```
